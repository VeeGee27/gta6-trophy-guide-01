An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5, with a roadmap to the Platinum, missable flags, filters, a spoiler shield and saved progress. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide is plain static files under app/, no build step, and it works with the network off.
